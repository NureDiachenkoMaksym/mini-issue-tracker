# Здавання через GitHub та DL

Автор: Дяченко Максим Михайлович, ПЗПІ-23-6.

Репозиторій: https://github.com/NureDiachenkoMaksym/mini-issue-tracker

Матеріали комплекту розміщуються окремими файлами: sources, docs, figma, verification, evidence, tools, submission. Історія підготовки до публікації не видається за git commits.

На DL потрібно завантажити лише файл readme.txt із цієї папки, за додатковим указанням викладача. Саме завантаження на DL виконується окремо; воно не підтверджене цим комплектом.

Перед здаванням перевірити доступ викладача до Figma Design → Present. Відкриті відхилення та межі перевірки наведено у README і verification/07_Final_Review_and_Test_Report_UA.md. Відеозвіт для заочного захисту ще не надано.
